# Raman Microscopy Cancer Staging Pipeline

MSc Advanced Computer Science — University of Leeds

Deep learning pipeline for classifying colon cancer stages from 
hyperspectral SRS Raman microscopy images.

## Cell Lines
- Healthy: FHC
- Dukes A: HCT116  
- Dukes B: SW480, CaCo2
- Dukes C: HT29, SW620

## Key Results
- Test Accuracy: 95% (border75px ResNet50)
- Macro F1: 0.956
- Macro AUC: 0.993
